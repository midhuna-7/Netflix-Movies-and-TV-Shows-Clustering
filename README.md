# 🎬 Netflix Movies and TV Shows Clustering

## 📌 Project Overview

This project applies Unsupervised Machine Learning techniques to cluster Netflix Movies and TV Shows based on their metadata such as genre, rating, duration, release year, and description.

The objective is to identify similar groups of content that can improve recommendation systems and provide useful business insights.

---

## 🎯 Problem Statement

Cluster Netflix content into meaningful groups using machine learning algorithms without predefined labels.

---

## 📁 Dataset

Rows: 7787

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. TF-IDF Vectorization
6. Feature Scaling
7. K-Means Clustering
8. Hierarchical Clustering
9. DBSCAN
10. PCA Visualization
11. Business Insights

---

## 📌 Results

- Successfully clustered Netflix content.
- Compared three clustering algorithms.
- K-Means produced the best overall clustering performance.
- Generated business insights for content recommendation.
